# D2 — Scale, loads, and the physics of a huge wing

Stream D2 of the Wing Lab. Subject: **what changes about the LOOK of one wing** when the
animal under it masses like a horse-to-elephant instead of a fox. Every physical fact below
is landed as a visual instruction. A fact that does not change a vertex is not in this file.

**Leapfrogs, does not restate:** `DRAGON-ANATOMY-REFERENCE.md` §2.7 (mass/span/honest
exaggeration), §4.5 (camber, AR, wing-loading band), §5.1 (f ∝ √(wing loading)). Those are
assumed read. D2's job is the *structure and material* consequences of the mass they imply —
the spar, the membrane, the failure modes — and the loads at 600–900 kg specifically.

`EGRESS_BLOCKED` on `en.wikipedia.org`; stream A1 confirmed the same on eight other domains).
Every `[S]` below therefore comes from a **`WebSearch` index summary of a named URL**, not from
the page body.

Convention, so the director can calibrate:

- `[S]` + URL — a real, retrievable, named source. The number came back attached to that URL.
- `[D]` — I computed it. The arithmetic is shown inline, every time, so it can be checked and
  overridden.
- `unknown` — searched, not found. Search terms given.
- `[no-assert]` — the literature actively disagrees. Both numbers given; neither picked.

**No number in this file was invented.** Where I wanted a number and could not source it, the
row says `unknown` and the derivation that needed it is marked as resting on an assumption.
